# Creepy-Code

**AIブライダルプランニング支援システム（P2C：Creepy Code）** の設計書・マニュアルと、アプリ本体（Spring Boot）をまとめて管理しているリポジトリです。

---

## 1. アプリの概要

結婚式を挙げる新郎新婦（顧客）と、式場のウエディングプランナーを AI でつなぎ、おふたりの理想に寄り添った結婚式プランの作成を支援する Web アプリケーションです。

### だれが使うか（利用者の種類と役割）
- **顧客（新郎新婦）**：事前ヒアリングや AI との深掘り質問に答えることで、自分たちの希望や大切にしたい価値観を明確にし、ぴったりなプランと見積もりを見つけることができます。
- **ウエディングプランナー**：AI がまとめた顧客の希望やプラン内容を確認し、式場のプロとしてより具体的なプランの提案・見積もり調整・チャット相談を行います。
- **管理者**：システム全体の管理、プランナーへの顧客の担当割り当て、料金マスタの設定などを行います。

---

## 2. アプリの流れ（主な機能）

システムは以下の流れで利用します。

```mermaid
graph LR
    A[会員登録・ログイン] --> B[事前ヒアリング]
    B --> C[AI深掘り質問]
    C --> D[マイプラン生成・料金試算]
    D --> E[AI相談・プランナー相談]
```

1. **会員登録・ログイン**（顧客・プランナー・管理者）
   - メールアドレスとパスワードでログインします。利用者の種別（顧客・プランナー・管理者）に応じて、専用の初期画面が表示されます。
2. **事前ヒアリング＆ AI 深掘り質問**
   - 挙式希望時期・人数・予算・重視したいテーマなどのアンケートに回答します。
   - 回答内容をもとに、AI がさらにふたりのこだわりや価値観を引き出す「深掘り質問」を行います。
3. **マイプラン作成・料金シミュレーション**
   - ヒアリングと深掘りの結果から、おふたりに合わせた結婚式プランが作成されます。
   - 料理・装花・演出などのオプションを変更しながら、リアルタイムに見積もり料金の増減をシミュレーションできます。
4. **AI チャット相談・プランナー相談**
   - 気になる疑問や演出の相談を AI と自由にやり取りできます。
   - 担当プランナーが決まると、プランナーとの直接チャットやプランの最終合意へ進むことができます。

## 3. 使っている技術

- **プログラミング言語・フレームワーク**：Java 17 / Spring Boot 3.5 / Maven
- **データベース**：Supabase（PostgreSQL。チーム全員で1つのプロジェクトを共有） / Spring Data JPA
- **画面（フロントエンド）**：Thymeleaf ＋ Thymeleaf Layout Dialect ＋ Bootstrap 5
- **認証・セキュリティ**：Spring Security（フォームログイン・BCrypt 暗号化）
- **AI 連携**：Sign in with ChatGPT（bridal-app が OpenAI の Responses API を直接呼びます。API キーは使わず、ChatGPT の有料プラン利用枠を使用）

アプリ本体は各自の PC（ローカル環境）で動かし、データベースのみインターネット上の Supabase に接続します。
データベースの接続情報などの秘密情報は環境変数で設定し、リポジトリ内には一切含めません。

## 4. 動かし方（ビルドと起動手順）

### 必要な環境
- Windows 10 / 11（64bit）
- Java 17（JDK 17）

### 必要な環境変数（データベース接続情報）
アプリを起動する前に、以下の3つの環境変数を設定してください。
公開リポジトリのため、秘密の値はリポジトリには書かれていません。具体的な値はチームの連絡帳（Discord 等）で共有されているものを使用してください。

| 環境変数の名前 | 説明 | 設定する値（例） |
| --- | --- | --- |
| `DB_URL` | Supabase（PostgreSQL）の接続先 URL | `jdbc:postgresql://<ホスト名>:5432/postgres?sslmode=require` |
| `DB_USERNAME` | データベースの接続ユーザー名 | `postgres.<プロジェクトID>` |
| `DB_PASSWORD` | データベースの接続パスワード | （チームで共有されたパスワード） |

---

### 起動手順 1：コマンドライン（PowerShell）で動かす場合

1. **bridal-app フォルダに移動**：
   ```powershell
   cd bridal-app
   ```

2. **テストを実行して確認**（省略可）：
   ```powershell
   .\mvnw.cmd test
   ```

3. **アプリを起動**：
   ```powershell
   .\mvnw.cmd spring-boot:run
   ```

4. **ブラウザで確認**：
   起動後、ブラウザで [http://localhost:8080](http://localhost:8080) にアクセスします。

---

### 起動手順 2：Eclipse（Pleiades）で動かす場合

1. **プロジェクトの取り込み**：
   - Eclipse のメニューから「ファイル」→「インポート」を開きます。
   - 「Maven」→「既存 Maven プロジェクト」を選び、`bridal-app` フォルダを指定して完了します。
2. **環境変数の設定**：
   - パッケージ・エクスプローラーで `bridal-app` を右クリックし、「実行」→「実行の構成」を開きます。
   - 「Spring Boot アプリケーション」（または「Java アプリケーション」）の対象設定を選び、「環境」タブを開きます。
   - 「新規」を押し、上記の3つの環境変数（`DB_URL`、`DB_USERNAME`、`DB_PASSWORD`）を登録します。
3. **起動**：
   - `BridalApplication.java` を右クリックして「実行」→「Spring Boot アプリケーション」で起動します。
   - ブラウザで [http://localhost:8080](http://localhost:8080) にアクセスします。

## 5. AI の使い方（Sign in with ChatGPT）

### 初期状態：ダミーモード（初期設定不要）
初期状態（環境変数 `APP_AI_MODE` を設定しない場合）は **「ダミーモード（`dummy`）」** で動作します。
固定の回答を返すため、ChatGPT の準備をしなくても画面の動作や通常の機能確認が行えます。

### 本物の AI（ChatGPT）を使う場合の手順
本物の AI を動かす場合は、中継プログラムは使わず、`bridal-app` が ChatGPT の利用枠を直接呼び出します。以下の手順で準備します。

1. **ChatGPT へのサインイン（本物の AI を使う PC で、最初の1回だけ）**：
   ```powershell
   cd bridal-app
   .\ai-account.cmd sign-in
   ```
   - ブラウザが開くので、ChatGPT にサインインしてプランの利用を許可します。
   - 戻り先の初期ポートは `1455` です。ほかのアプリが使っているときは `.\ai-account.cmd sign-in --port 番号` と指定します。
   - サインインの状態は `.\ai-account.cmd status` で確かめられます。サインイン情報を消すときは `.\ai-account.cmd sign-out` を使います。
   - サインイン情報は `C:\Users\<ユーザー名>\.creepy-code\chatgpt-java` に保存されます（`CREEPY_CODE_HOME` を設定したときは、その下の `chatgpt-java`）。Windows の機能（DPAPI）で暗号化して保存します。
   - 保存先はそのユーザーの PC の中にあるため、本物の AI を動かす PC ごとに、最初の1回サインインします。
   - 古い `%USERPROFILE%\.creepy-code\devkit` と `chatgpt` フォルダは要らなくなったので、自分で消してよいです。
2. **アプリ側の設定と起動**：
   - Windows の環境変数 `APP_AI_MODE` に `chatgpt` を設定します。
   - Eclipse またはターミナルを再起動し、環境変数を反映させてから `bridal-app` を起動します。
   - `chatgpt` で起動したとき、サインインしていなければ起動後に自動でサインインを始めます（環境変数 `APP_AI_AUTO_SIGN_IN` の初期値は `true`）。

### AI 関連の環境変数一覧

| 環境変数の名前 | 設定する値 | いつ設定するか | 根拠 |
| --- | --- | --- | --- |
| `APP_AI_MODE` | `chatgpt`（本物の AI）／`dummy`（固定の文章。未設定ならこちら） | **本物の AI を使う PC だけ** | `bridal-app/src/main/resources/application.properties:56` |
| `APP_AI_AUTO_SIGN_IN` | 初期値 `true` | 起動時の自動サインインを止めたいときだけ `false` | `bridal-app/src/main/resources/application.properties:58` |
| `APP_AI_MODEL` | 初期値 `gpt-6-luna` | 使用する AI モデルを変更するときだけ | 同:61 |
| `CREEPY_CODE_HOME` | 未設定なら `C:\Users\<ユーザー名>\.creepy-code` | サインイン情報の保存先を変えるときだけ（その下に `chatgpt-java` を作る） | `bridal-app/src/main/java/com/creepycode/common/ai/chatgpt/ChatGptCredentialStore.java:36-37, 62-73` |

> [!NOTE]
> - `application.properties` にある `app.ai.mode` などの項目は**アプリ内部の設定名**であり、環境変数そのものではありません。メンバーは `application.properties` を直接書き換えないでください。
> - API キーは使用しません。

## 6. フォルダ構成

```
Creepy-Code/
├─ bridal-app/        … アプリ本体（Spring Boot / Java 17）
├─ db/                … Supabase で実行する SQL（テーブル定義・マスタ・テストデータなど）
│   ├─ 00〜06_*.sql         … スキーマ・テーブル・マスタ・テストデータ・画像の投入など（番号の順。管理担当が Supabase の SQL Editor で実行する）
│   └─ 保留/                … 全テーブル削除の SQL（ふだんは実行しない）
├─ .agent-memory/     … チームの長期記憶（決定事項・共有知識）
└─ docs/
    ├─ 00_ブライダル業界/   … 業界調査・基本設計書
    ├─ 01_テンプレート/
    ├─ 02_提出物/
    ├─ 03_Git&Sourcetree操作マニュアル/
    └─ 04_開発ルール/       … コーディング規約
```
