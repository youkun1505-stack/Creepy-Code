# 環境構築手順書

AIブライダルプランニング支援システム（P2C：Creepy Code）

作成日：2026-10-07

この手順書のとおりに進めると、自分の PC（Windows）でアプリ `bridal-app` を起動できるようになります。

---

## 1. 前提（先に入っているもの）

次のものが PC に入っていることを確認してください。どれも授業で使っているものです。

| もの | 何に使うか |
|---|---|
| Pleiades 2023-12（Eclipse） | プログラムを書いて、アプリを起動する |
| Docker Desktop | Oracle のデータベースを動かす入れ物（コンテナ）を動かす |
| 授業で作った Oracle のコンテナ | データベース本体。新しく作る必要はない |
| Oracle SQL Developer | データベースの中身を見たり、SQL を実行したりする |
| SourceTree | Git（ファイルの変更履歴を管理するしくみ）を画面で操作する |

---

## 2. リポジトリをクローンする

リポジトリ（チームのファイル置き場）を、自分の PC にコピー（クローン）します。

1. SourceTree を開き、「Clone」を押す。
2. 元のパスに GitHub の Creepy-Code の URL を入れる。
3. 保存先のパスを **`C:\pleiades\2023-12\workspace\Creepy-Code`** にする。
4. 「クローン」を押す。

> **OneDrive の中には置かないでください。** OneDrive が自動で同期するときにファイルをロック（使用中にする）するため、ビルドや Git の操作が失敗することがあります。

---

## 3. Oracle のコンテナを起動する

1. Docker Desktop を開く。
2. 左のメニューの「Containers」を押す。
3. 授業で作った Oracle のコンテナ（`oracle-xe` や `oracle21c` など。**名前は人によって違ってよい**）の ▶（Start）を押す。
4. 起動してからデータベースが使えるようになるまで 1〜2 分かかるので、少し待つ。

> Oracle のコンテナが2つある人は、**1つだけ**起動してください（どちらもポート1521を使うため、同時には動きません）。

---

## 4. CREEPY ユーザー（スキーマ）を作る

このプロジェクト専用のユーザー `CREEPY` を作ります。Oracle では「ユーザー」と「スキーマ（テーブルを入れる箱）」は同じもので、ユーザーを作ると同じ名前の空のスキーマができます。授業で使っているユーザー（`SPRING_USER` など）とは別の箱なので、授業のデータには影響しません。

### 4-1. SYSTEM の接続を作る（授業で作ってあれば不要）

1. SQL Developer を開く。
2. 左の「接続」パネルの「＋」（新規接続）を押す。
3. 次のとおり入力する。

   | 項目 | 値 |
   |---|---|
   | Name | `XEPDB1_SYSTEM`（わかりやすい名前なら何でもよい） |
   | ユーザー名 | `system` |
   | パスワード | 授業で設定したもの（初期値は `systemsss`） |
   | ホスト名 | `localhost` |
   | ポート | `1521` |
   | サービス名 | `XEPDB1` |

4. 「テスト」を押し、左下に「ステータス: 成功」と出たら「保存」→「接続」を押す。

### 4-2. `db/00_create_user.sql` を実行する

1. メニューの「ファイル → 開く」から、`C:\pleiades\2023-12\workspace\Creepy-Code\db\00_create_user.sql` を開く。
2. 右上の接続の選択欄で、4-1 で作った SYSTEM の接続を選ぶ。
3. 「スクリプトの実行」（紙とページの絵のボタン、または **F5** キー）を押す。
4. 下の「スクリプト出力」に、ユーザーが作成されたことと、権限の付与（Grant）が4回成功したことが表示され、`ORA-` で始まるエラーが1つも無ければ成功。

> もう一度実行すると `ORA-01920` のエラーが出ますが、「すでに作ってある」という意味なので問題ありません。

> `db/保留/` の中の SQL（テーブル作成など）は、**今は実行しないでください。** 実行するタイミングはチームで決めます。

---

## 5. CREEPY の接続を作る

アプリが使うユーザーで、SQL Developer からも接続できるようにしておきます。

1. 4-1 と同じく「＋」（新規接続）を押し、次のとおり入力する。

   | 項目 | 値 |
   |---|---|
   | Name | `XEPDB1_CREEPY` |
   | ユーザー名 | `CREEPY` |
   | パスワード | `creepycode` |
   | ホスト名 | `localhost` |
   | ポート | `1521` |
   | サービス名 | `XEPDB1` |

2. 「テスト」を押し、「ステータス: 成功」と出たら「保存」→「接続」を押す。
3. 今はまだテーブルが無いので、左の「表」を開いても中は空です。それで正しい状態です。

---

## 6. Eclipse にプロジェクトを読み込む

1. Eclipse（Pleiades 2023-12）を開く。ワークスペースは `C:\pleiades\2023-12\workspace` を選ぶ。
2. メニューの「ファイル → インポート」を押す。
3. 「Maven → 既存 Maven プロジェクト」を選んで「次へ」を押す。
4. 「ルート・ディレクトリー」の「参照」から `C:\pleiades\2023-12\workspace\Creepy-Code\bridal-app` を選ぶ。
5. `/pom.xml` にチェックが入っていることを確認して「完了」を押す。
6. 右下に進み具合が表示され、必要なライブラリ（部品）のダウンロードが始まる。初回は数分かかるので、終わるまで待つ。

---

## 7. アプリを起動する

1. 左の「パッケージ・エクスプローラー」で `bridal-app → src/main/java → com.creepycode → BridalApplication.java` を開く。
2. `BridalApplication.java` を右クリック →「実行 → Spring Boot アプリケーション」を押す。
   （メニューに無い場合は「実行 → Java アプリケーション」でも起動できます）

---

## 8. 起動できたか確認する

下の「コンソール」に、次の行が出れば完了です。

```
HikariPool-1 - Start completed.
```

これは「データベース（CREEPY）への接続に成功した」という意味です。続けて `Started BridalApplication` と出れば、アプリの起動も完了しています。

> ブラウザで http://localhost:8080 を開くと、Spring Security（ログイン機能の部品）の標準のログイン画面が出ます。画面はまだ作っていないので、これで問題ありません。

止めるときは、コンソールの右上の赤い四角（終了）を押します。

---

## 9. AI（Gemini API）を使うとき

初期状態では、AI は固定の文章を返す「ダミーモード」で動きます。本物の Gemini API を使うときだけ、次の設定をします。

1. Google AI Studio で API キー（AI を使うための合言葉）を発行する。2026年6月以降は「Gemini API 専用」の制限が付いたキーでないと使えません。
2. Windows のスタートメニューで「環境変数」と検索し、「環境変数を編集」を開く。
3. 上の「ユーザー環境変数」の「新規」から、次の2つを追加する。

   | 変数名 | 値 |
   |---|---|
   | `GEMINI_API_KEY` | 発行した API キー |
   | `APP_AI_MODE` | `api` |

4. **Eclipse を再起動する**（再起動しないと、新しい環境変数が読み込まれません）。

> **API キーは、リポジトリのファイルには絶対に書かないでください。**
> 無料枠では、送った内容が Google のサービス改善に使われます。**架空のテストデータだけ**を使い、実在の人の個人情報は送らないでください。

ダミーモードに戻すときは、`APP_AI_MODE` を `dummy` にする（または削除する）して、Eclipse を再起動します。

## 11. よくあるトラブル

| 症状 | 原因 | 対処 |
|---|---|---|
| `ORA-12514`（リスナーはサービスを認識していません） | データベースがまだ起動しきっていない／サービス名の打ち間違い | 1〜2分待ってからやり直す。サービス名が `XEPDB1` になっているか確認する |
| `ORA-01017`（ユーザー名/パスワードが無効） | ユーザー名・パスワードの間違い／CREEPY をまだ作っていない | 接続の設定を確認する。CREEPY が無い場合は手順4をやり直す |
| `Port 8080 was already in use` | 別のアプリ（授業のアプリなど）が 8080 番を使っている | コンソールの赤い四角で、動いている別のアプリを止めてから起動し直す |
| `UnsupportedClassVersionError` や、Java のバージョンのエラー | Eclipse が Java 17 以外を使っている | `bridal-app` を右クリック →「Maven → プロジェクトの更新」。直らなければ「プロパティ → Java のビルド・パス → ライブラリー」で JRE が 17 になっているか確認する |
| 日本語が文字化けする（Eclipse） | ファイルの文字コードが UTF-8 になっていない | 「ウィンドウ → 設定 → 一般 → ワークスペース」の「テキスト・ファイルのエンコード」を `UTF-8` にする |
| 日本語が文字化けする（SQL Developer） | SQL ファイルの文字コードの設定 | 「ツール → プリファレンス → 環境」の「エンコーディング」を `UTF-8` にして、ファイルを開き直す |
| ライブラリのダウンロードが終わらない／赤いエラーが消えない | ダウンロードの途中で失敗した | `bridal-app` を右クリック →「Maven → プロジェクトの更新」で「スナップショット/リリースの強制更新」にチェックを入れて OK |
