# 基本設計書 v1.6 変更内容まとめ

改訂日：2026-10-07　（v1.5 からの変更点）

環境構築の方針決めで決まった次の3点を、設計書に反映した版です。v1.5 はそのまま残しています。図（画面遷移図・ER図）は v1.5 から変更していません。

1. 開発・発表は各メンバーのPC（ローカル環境）で行い、AWS には配置しない
2. AI サービスを Claude API から Gemini API（Google・無料枠）に変更する
3. DB アクセスは JDBCテンプレート ではなく Spring Data JPA を使う（授業で習った方式に合わせる）
