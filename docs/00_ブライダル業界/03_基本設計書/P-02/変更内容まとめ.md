## 設計書に無い追加（P-02 の画面）

- 「すでに会員の方は ログイン」のリンク（間違えて会員登録の画面に来た人の逃げ道）
- パスワードの条件（8文字以上で、半角の英字と数字を両方含む）を、エラーになる前から入力欄の下に書いておく
- パスワード欄の「表示／隠す」の切り替え（パスワード・確認用の両方）
- エラーがあるときは、フォームの上に「入力内容に誤りがあります」のまとめを出し、各項目のすぐ下にも理由を出す。氏名とメールアドレスは入力したまま残し、パスワードは空に戻す
- 画面の左側に「登録すると、できること」（3つ）と「登録したあとの流れ」（会員登録・かんたんな質問・AIのたたき台・プランナーに相談）を出す

## P-02 の画面の詳細（実装に合わせた補足）

ハリボテ（`bridal-app` の `auth/controller/RegisterController.java`・`auth/dto/RegisterForm.java`・`auth/service/RegisterService.java`・`templates/auth/register.html`、ログイン（P-03）と共通の `templates/common/auth-merit.html`・`css/auth.css`・`js/auth.js`）で作った内容は次のとおりです。

### 画面構成（PC 基準・2列）

| 列 | 内容 |
|---|---|
| 左 | 登録すると、できること／登録したあとの流れ（いまの段階に「いまここ」） |
| 右 | 会員登録のフォーム（氏名・メールアドレス・パスワード・パスワード（確認用））と［登録する］ボタン、ログインへのリンク |

タブレット・スマホでは1列にして、フォームを先に、説明を後に並べます。

### 入力チェック

| 項目 | 決まり | エラーの文言 |
|---|---|---|
| 氏名 | 必須・100文字以内（T-01 USERS.NAME） | 氏名を入力してください／氏名は100文字以内で入力してください |
| メールアドレス | 必須・メールアドレスの形・255文字以内（T-01 USERS.EMAIL）・登録済みでない | メールアドレスを入力してください／メールアドレスの形で入力してください（例：hanako@example.com）／このメールアドレスはすでに登録されています。ログインしてください |
| パスワード | 必須・8文字以上で、半角の英字と数字を両方含む（6-2） | パスワードを入力してください／パスワードは8文字以上で、半角の英字と数字を両方含めてください |
| パスワード（確認用） | 必須・パスワードと同じ | 確認用のパスワードを入力してください／パスワードと確認用のパスワードが一致しません |

入力チェックはサーバー側で行います（ブラウザの入力チェックの吹き出しは止めて、メッセージの出し方をそろえています）。

### ハリボテ用の仮の仕組み

- DB には保存しません。［登録してはじめる］を押して入力に問題がなければ、保存せずにログイン後のハブ（仮の URL `/after-login-tmp` の「まだ何もしていない」状態）へ進めます。
- 本当のログインはしていません。ハブのヘッダーには、登録した直後だけ、入力した氏名を「〇〇 様」と出します（それ以外は、これまでどおりテストデータの「テスト 顧客」）。
- 登録済みのメールアドレスのチェックは仮です。`test@example.com` だけを「登録済み」として扱います（大文字・小文字は区別しません）。
- ログイン（P-03）はまだ無いので、ログインへのリンクは仮の URL `/auth/login` です。

## レビュアー・チームに確認してほしい点

- パスワードに使える文字：設計書は「半角英数字の両方を含む」です。P-02 では、半角の記号（`!` や `@` など）も使えるようにしています（英字と数字を1文字ずつ以上含めば可）。記号を使えないようにするかを決めてください。
- 登録と同時に自動でログインさせる点：ログイン機能（P-03）を作るときに、登録した会員をそのままログイン状態にする処理が必要です（`RegisterController.java` に TODO を残しています）。P-01 反映版の「ログインした顧客の行き先」とあわせて、ログイン機能の担当と確認してください。
- 本当に保存するとき（USERS ができたら）：パスワードの BCrypt でのハッシュ化、ROLE は CUSTOMER、論理削除済み（DELETED_AT あり）のメールアドレスで再登録できるかを決めてください（`RegisterService.java` に TODO を残しています）。
