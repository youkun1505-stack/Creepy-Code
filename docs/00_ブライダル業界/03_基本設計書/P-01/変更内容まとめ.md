## P-01 の画面の詳細（実装に合わせた補足）

設計書本文には要点だけを書いています。ハリボテ（`bridal-app` の `TopController.java`・`common/top.html`・`css/top.css`）で作った内容は次のとおりです。

### 画面構成（PC 基準・3列）

| 列 | 未ログイン | ログイン後（顧客） |
|---|---|---|
| 左 | 今の流行（中身は検討中。いまは「準備中」の枠だけ。枠の中だけスクロール） | 同じ |
| 中央 | サービスの説明／ご利用の流れ（4ステップ） | 次にやること／進み具合（5段階） |
| 右 | 会員登録・ログインのボタン／ページ内リンク（スクロールしても付いてくる） | 各画面へのメニュー（押せない項目は理由を表示） |

タブレット・スマホでは1列に並べ替えます（未ログイン：メニュー → 本文 → 今の流行／ログイン後：本文 → メニュー → 今の流行）。

### ログイン後の状態ごとの表示

| 状態 | 次にやること（ボタン） | 進み具合の「いまここ」 | マイプラン・料金 | プランナーとのチャット |
|---|---|---|---|---|
| かんたん質問がまだ | まずはかんたんな質問に答えてみましょう（はじめる） | かんたん質問 | 押せない：AIがプランを作ると見られます | 押せない：マイプランで「プランナーに相談する」を選ぶと使えます |
| かんたん質問の途中 | かんたん質問の続きから（続きをはじめる） | かんたん質問 | 押せない（同上） | 押せない（同上） |
| プラン作成済み・相談前 | AIのプランを確かめましょう（マイプランを見る） | 担当プランナー決定 | 押せる | 押せない（同上） |
| 担当を決めている | 担当プランナーを決めています（料金シミュレーションを開く） | 担当プランナー決定 | 押せる | 押せない：担当プランナーを決めています。決まるとここから相談できます |
| 担当が決まった | 担当プランナーが決まりました（プランナーとチャットする） | 合意 | 押せる | 押せる |

「AIに相談する」（P-10）は、どの状態でも押せます。

### ハリボテ用の仮の仕組み

- ログイン機能がまだ無いので、ログイン後の表示は仮の URL `/after-login-tmp` で確認します。末尾の `?state=` で状態を切り替えます（`new`（初期値）／`hearing`／`plan`／`assigning`／`assigned`）。
- 本番では URL で切り替えず、ログイン中の顧客のデータから状態を決めます。ログイン機能ができたら `/after-login-tmp` は削除します。
- 会員名は、テストデータの顧客「テスト 顧客」を仮に表示しています（本番は USERS.NAME）。
- まだ無い画面への行き先は仮の URL です（`/auth/register`・`/auth/login`・`/hearing/step1`・`/hearing/step2`・`/plan/myplan`・`/plan/simulation`・`/chat`・`/logout`）。

## レビュアー・チームに確認してほしい点

- ログインした顧客の行き先：設計書では「ログイン後は Step1（P-06）へ」のままです。P-01 をホームにしたので、ログイン後は P-01 へ移すかどうかを決めてください（本書はまだ変えていません）。
- マイプラン（P-12）のチャットへのリンク：設計書では「担当が決まるまで表示しない」です。P-01 に合わせて「押せない＋理由の表示」にそろえるかを決めてください（本書はまだ変えていません）。
- 各画面の URL：設計書に決まりが無いため、P-01 では仮の URL を使っています。画面番号と URL の対応表をチームで決めると、つなぎ直しが減ります。
- 「担当プランナーを決めています」の推定待ち時間（5-2）の出し方と、「今の流行」の中身（取得元）は未定です。
- P-10 を Step1 の前に開いた場合、AI が質問を作る材料（Step1〜4 の回答）がほとんどありません。そのときの質問の作り方を、P-10 の担当と決めてください。
- P-10 の画面（`hearing/deepdive.html`）の main に `class="container site-main"` が無く、余白と横幅の制限が効いていません（共通レイアウトの main は各画面の main で置き換わるため）。
- 本書の 1章・3章などには、Gemini API と Oracle の記載が残っています（チームは Sign in with ChatGPT と Supabase に変更済み）。P-01 反映版では触れていないので、別途更新してください。
