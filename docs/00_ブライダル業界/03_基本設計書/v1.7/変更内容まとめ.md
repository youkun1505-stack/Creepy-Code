## 実装に合わせた補足

設計書本文には要点だけを書いています。作った画面（`bridal-app`）の細かい動きは次のとおりです。

### かんたん質問 Step1〜4 の画面の流れ

| 画面 | URL | 次へ進む先 |
|---|---|---|
| Step1（P-06）どんな式にしたい？ | `/hearing/step1` | Step2 |
| Step2（P-07）好きな雰囲気は？ | `/hearing/step2` | あなたの好み（`/hearing/step2/result`）→ Step3 |
| Step3（P-08）日程 | `/hearing/step3` | Step3 予算 |
| Step3（P-08）予算 | `/hearing/step3/budget` | Step4 |
| Step4（P-09）気になることはある？ | `/hearing/step4` | AIに相談する（`/hearing/deepdive`） |

- 前の Step に答えていないときは、答えていない Step へ戻します。Step3・Step4 は「Step2 まで答えたか」で決めます（Step3 は「まだ決まっていない」も NULL なので、答えたかを見分けられないため）。
- Step2 の細かいテイスト（2回目に比べる2枚）：ナチュラル（ガーデン／ボタニカル）、華やか（ラグジュアリー／プリンセス）、シック・大人（モダン／クラシック）、かわいい・淡色（淡色・韓国風／ガーリー）、和（伝統／和モダン）、個性・ふたりらしさ（趣味・テーマ／カジュアル・フェス）。画像は今は仮の画像（18枚）です。
- Step4 の「おすすめ」の組み合わせは、`hearing/service/HearingTag.java` の各タグにある「おすすめ先」に書いています。
- カップル像の入れ替えは `db/04_update_archetype_master.sql`・`db/05_add_archetype_simple.sql`、Step2 の画像は `db/06_insert_visual_images.sql` です（共有 Supabase で実行する SQL として db/ 直下に置いているもの）。

### P-01（ハブ）の細かい決め方

- まだ答えていない最初の Step：Step1（ARCHETYPE_ID が空）→ Step2（VISUAL_SELECTIONS が空）→ Step4 の答えが NULL のときは、日程と予算の両方が入っていれば Step4、どちらかが空なら Step3 から（「まだ決まっていない」と「答えていない」が区別できないため、Step3 からやり直してもらう）。
- 進み具合（5段階）の名前と「いまここ」：かんたん質問（①②）／AIの質問に答える／プラン作成（③④）／担当プランナー決定（⑤⑥）／合意（⑦）。
- プランナーに送った後にかんたん質問を開こうとしたときは、トップページ（P-01）に「プランナーに送った後の変更は、担当プランナーにお伝えください。」を一度だけ出します。

### P-11（生成中）の動き

- 画面を開くと、`js/plan.js` が `POST /plan/generating` を呼びます。返事は次の5種類です。

| 返事 | 画面の動き |
|---|---|
| できた・もうできていた | マイプラン（P-12）へ進む（失敗の回数を消す） |
| 別の呼び出しが作っている最中 | 3秒待ってから、もう一度聞く（失敗には数えない） |
| 失敗した | 「プランを作れませんでした」と［やり直す］。3回続けて失敗したら、お店（プランナー）に相談する案内 |
| Step4 まで答えていない | トップページ（P-01）へ戻す |
| プランナーに送った後 | マイプランへ進む |

- 30秒たっても終わらないときは「時間がかかっています」と［やり直す］を出します（そのまま待ち続けることもできます）。1回の問い合わせは60秒で打ち切ります。
- 失敗の回数は、ログイン中の間だけ覚えます（成功したら消します）。
- 同じ顧客の生成が重ならないよう、1つずつ行います。AI を待つ間は DB の接続を使いません（接続は1人2本までのため）。

### P-12（マイプラン）の表示

- いまの状態（画面に出す状態名）、プランの大枠11項目（提案・そう考えた理由）、価値観の要点（大事にしていること・削ってもよい部分・削ってよい順。無いときは「特にありません」）を出します。
- 作成中で大枠がまだ無いときは、生成中（P-11）へ進めます。データが欠けて表示できないときは「プランを表示できませんでした。お手数ですが、お店にお問い合わせください。」を出します。
