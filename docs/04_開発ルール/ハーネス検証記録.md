## 仕様の確認（2026-10-18、Claude Code 公式の説明）

確かめたページ：https://code.claude.com/docs/en/sub-agents 、https://code.claude.com/docs/en/settings-reference

- 役の定義ファイルで必須なのは `name`・`description` だけ。`tools`・`disallowedTools`・`model`（`sonnet`・`opus`・`haiku`・`fable`・正式なモデル名・`inherit`）・`effort`（`low`〜`max`）が使える。知らない項目は、エラーにならずに無視される。
- 役は新しい記憶で起動し、会話の流れを引き継がない。呼ぶ側が書いた依頼文から作業する。会話をまるごと引き継ぐ `fork`（`/subtask`）は例外。
- 役の中から別の役を呼ぶには、`tools` に `Agent` を入れる。ただし `Agent(役の名前)` で相手を限る書き方は、役の中では無視される（`claude --agent` で起動したときだけ効く）。
  そのため、「呼んでよい役」は指示で守る決まりになる。
- 呼び出しの深さは `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`、同時に動く数は `CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS`（初期値 20）で変えられる。
  `.claude/settings.json` の `env` に書く方法は公式の例どおり。実際に効くかは未確認。役の中から呼んだ役が同時に動く数に入るかは、説明からははっきりしない（入ると考えて手順を決めた）。
- `model`・`effortLevel` は `.claude/settings.json` に書ける。自分だけ変えたいときは `.claude/settings.local.json` に書く。`/model`・`/effort` で途中から変えることもできる。

### 2026-10-18 役のモデルを変え、格上げの仕組みを入れたとき

設定に書いたこと：

- 司会役は Opus 5.5／`medium`（変えていない）。設計役・レビュー役は Sonnet 5.5／`high`。調査役・テスト役・GitHub 係は Haiku 5.5／`low`。
  実装役・記録係・文脈係は Haiku 5.5／`medium`。ハーネス点検は Haiku 5.5／`high`。
- Haiku 5.5 の役が難しくて終えられないときは `止まった` で返し、司会役が Agent ツールの `model` に `sonnet` を指定して呼び直す。
  Sonnet 5.5 でもだめなら司会役が判断し、必要ならメンバーに相談する。

この強さを選んだ根拠（2026-10-18 に確認）：

- Claude 公式の Effort の説明と Prompting Claude Haiku 5.5 の説明。Haiku 5.5 は `medium` が初期値。`low` は短い道具の作業向けで、長い指示文の作業では検索を飛ばす・途中でやめることが増える。
  `high` は長めの作業や指示を厳しく守らせたい作業向け。`xhigh`・`max` は Sonnet 5.5 と比べてから使う、とある。
  - https://platform.claude.com/docs/en/build-with-claude/effort
  - https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-haiku-5-5
- 個人のブログでは、調査役・テスト実行役を Haiku／`low` にする例が多かった（数字は確かめていない）。

確かめられなかったこと：

- 変更後のモデルで各役が動くか、`haiku` が Haiku 5.5 を指すか。このセッションでは、変更前の定義が読み込まれているため。
- 格上げ（`model` に `sonnet` を指定した呼び直し）が、定義ファイルの `model` より優先されるか。公式の説明では、呼び出しごとの `model` が定義ファイルより優先される
  （https://code.claude.com/docs/en/sub-agents ）。実際の呼び出しでは未確認。

### 2026-10-18 モデルを正式な名前で固定したとき

設定に書いたこと：

- 役の定義ファイルの `model` を `claude-haiku-5-5`・`claude-sonnet-5-5` に、司会役の `model` を `claude-opus-5-5` にした（略した名前をやめた）。
- `.claude/settings.json` の `env` に `ANTHROPIC_DEFAULT_OPUS_MODEL`・`ANTHROPIC_DEFAULT_SONNET_MODEL`・`ANTHROPIC_DEFAULT_HAIKU_MODEL` を書き、
  略した名前（格上げで Agent ツールに指定する `sonnet` など）も 5.5 に固定した。

理由（Claude Code 公式の Model configuration、2026-10-18 に確認、https://code.claude.com/docs/en/model-config ）：

- 略した名前は、窓口ごとのおすすめの版を指し、時期によって変わる。Anthropic では 5.5 を指すが、Bedrock・Google Cloud などでは Sonnet 4.5・Haiku 4.5 などを指す。
- 版を固定するには、正式な名前を書くか、`ANTHROPIC_DEFAULT_*_MODEL` を設定する、とある。
- 役の定義ファイルの `model` に正式な名前（例：`claude-opus-5-5`）を書けることは、Subagents の説明にある。

確かめられなかったこと：

- 変更後に、各役と司会役が正式な名前どおりのモデルで動くか。`env` の固定が、格上げの `sonnet` 指定にも効くか。
- `ANTHROPIC_DEFAULT_HAIKU_MODEL` は、公式の説明に Opus・Sonnet の変数と並んで「略した名前の指す先を決める」と書かれていた（レビュー役が確認）。実際の動作は未確認。
- 前の記録の「`haiku` が Haiku 5.5 を指すか」は、正式な名前に変えたので、今後は確かめる必要がない。
