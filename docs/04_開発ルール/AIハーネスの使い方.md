# AIハーネスの使い方

AI に実装を頼むときの決まりごとをまとめた仕組みです。新しいコマンドや追加の道具は使いません。
Claude Code（Claude デスクトップアプリの「Code」や、VS Code などで使う Claude Code）でこのリポジトリを開くと、
次のファイルが自動で読み込まれ、AI がその決まりどおりに動きます。

| ファイル | 役割 |
| --- | --- |
| `AGENTS.md` | すべての AI が守るルール（Codex もこれを読む） |
| `CLAUDE.md` | Claude Code 用の進め方（`AGENTS.md` を読み込んだうえで、役割の分け方を足したもの） |
| `.claude/agents/implementer.md` | 実装役（軽いモデル） |
| `.claude/agents/reviewer.md` | レビュー役（賢いモデル） |
| `.claude/settings.json` | AI にさせない操作（取り込みなど）、毎回確認する操作、Claude Code のフック |
| `.githooks/` | Git のフック。人が操作しても AI が操作しても、Git のルールに合わないコミット・送信を止める |
| `.harness/templates/` | 作業メモ・チケット・引き継ぎ記録のひな形 |

## 仕組み

1. メインの会話の AI が「司会役」になり、あなたと一緒に作業メモ（目的・機能ごとの受け入れ条件・変更してよい範囲）を作ります。
2. 機能ごとに、実装役が作り、別の記憶を持つレビュー役が確かめます。レビュー役の指摘は「チケット」として残ります。
3. 重い指摘がなくなるまで「直す → 確かめる」を自動で繰り返します（1機能で3回まで。超えたら相談されます）。
4. 終わった機能から、作業ブランチにコミットされます。GitHub への送信と PR 作成は、あなたが「はい」と言ったときだけです。

## 頼み方の例

| やりたいこと | 話しかける例 |
| --- | --- |
| 新しい作業を始める | 「issue #12 のプラン提案画面を作りたい。作業メモから一緒に作って」 |
| 作業メモで進める | 「この作業メモで進めて」 |
| 様子を聞く | 「いまどこまで進んだ？残っているチケットは？」 |
| 今日の作業を終える | 「今日はここまで」 → 次にやることを聞かれるので答える |
| 別の人の続きをする | 「feature/12-plan-view の続きをやる」 |
| GitHub に送る | 「送って PR を作って」 → 内容を確認して「はい」 |

## AI がしないこと

- `main`・`develop` への直接の送信、強制送信、取り込み（merge）、`reset --hard`、ブランチの削除
- `main`・`develop` の上でのファイル変更やコミット（作業の前に必ずブランチを確認します）
- 作業メモの「変更してよい範囲」の外の変更
- API キーなどの秘密情報を書くこと、`CLAUDE.md`・`AGENTS.md`・`.claude/` の変更（リーダーに頼まれたときを除く）

## 作業の記録の置き場所

`.harness/tasks/<ブランチ名の / を - にした名前>/` に置かれます。

- `task.md`（作業メモ）と `handoff.md`（引き継ぎ記録）は Git で共有されます。
- `tickets/`（レビューの指摘）は一時的なもので、Git では共有されません。未解決のものは引き継ぎ記録に要約されます。

## Git のフック（自動の見張り）

`.githooks/` のフックが、コミットと送信の直前に自動で確かめます。人が SourceTree で操作したときも同じように止まります。

| 止めるもの | 表示される理由の例 |
| --- | --- |
| `main`・`develop` へのコミット | いまのブランチは「develop」です。main・develop には直接コミットできません |
| 決まりに合わないブランチ名 | feature/〇〇・fix/〇〇・docs/〇〇 の形にしてください |
| 決まりに合わないコミットメッセージ | 例：feat: プラン提案画面を追加 |
| `main`・`develop` への送信 | 作業ブランチを送信して、develop 向けの PR を作ってください |
| 強制送信・GitHub のブランチ削除 | 強制送信はしない決まりです |

Claude Code でこのリポジトリを開くと、フックは自動で有効になります。Claude Code を使わずに SourceTree だけで
作業する人は、一度だけリーダーに有効にしてもらってください（`git config core.hooksPath .githooks`）。

## リーダーにお願いしたいこと

AI への決まりは、すべての書き方を防げるわけではありません。確実に止めるため、GitHub の設定で
`main` と `develop` を保護し（直接の送信を禁止し、PR を必須にする）、取り込みは人が行う運用にしてください。
